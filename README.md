grandma-word is a tiny program that writes the one word a grandma would text about AI to a file: "contraption" — the word grandmothers reach for when a new machine appears in the house, warm and a little baffled, aimed at the thing itself rather than at any explanation of it. One word, nothing else: no sentence, no caption, no punctuation tricks.

## Run it

```sh
python3 main.py
```

It writes the word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
